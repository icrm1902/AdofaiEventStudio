# ADOFAI 事件工坊 1.0.0 操作手册

- 作者：橚
- 适用工具：Unity Mod Manager 0.32.4.0
- 适用游戏：A Dance of Fire and Ice
- 主要入口：游戏关卡编辑器左侧“事件工坊”页签

## 1. 功能概览

事件工坊用于在 ADOFAI 关卡编辑器中批量生成、复制、调整和删除事件与装饰。

主要功能：

- 批量生成普通事件
- 批量生成装饰
- 推广移动装饰动画
- 批量移动事件楼层
- 批量调整数值参数
- 批量删除事件
- 数值表达式
- 文本序号表达式
- 文件路径表达式与文件选择
- 中英文界面切换

## 2. 安装与打开

### 2.1 安装

将发布 ZIP 直接通过 UMM 的 **Install Mod** 安装，或解压到：

```text
A Dance of Fire and Ice\Mods\AdofaiEventStudio\
```

模组目录中应包含：

```text
AdofaiEventStudio.dll
Info.json
```

### 2.2 打开事件工坊

1. 启动游戏。
2. 进入关卡编辑器并打开一个可编辑关卡。
3. 在编辑器左侧找到“事件工坊”页签。
4. 点击页签进入操作菜单。

UMM 设置窗口现在只保留语言切换、当前编辑器状态和说明。所有批处理功能都在编辑器左侧的“事件工坊”中。

## 3. 界面语言

在 UMM 的“事件工坊”设置窗口顶部可以选择：

- 跟随游戏
- 中文
- English

事件类型和参数名称优先使用游戏自身的本地化文本。

## 4. 一级菜单

事件工坊左侧包含以下一级菜单：

1. 批量生成
2. 批量装饰
3. 推广
4. 批量调整
5. 批量删除

每个功能都采用逐级菜单引导。参数输入框默认留空。

## 5. 参数填写规则

### 5.1 留空

参数留空时：

- 使用游戏自带的默认值。
- 默认关闭的参数保持关闭。
- X/Y 分量分别回退到默认分量。

### 5.2 已填写

参数填写内容后：

- 生成时会写入该参数。
- 对应参数会被启用。
- X/Y 分量填写任意一个，也会启用对应的基础参数。

### 5.3 整数与浮点

- 浮点字段直接使用表达式结果。
- 整数字段直接去掉小数部分，不四舍五入。

例如整数结果：

```text
1.9  → 1
-1.9 → -1
0.99 → 0
```

## 6. 批量生成事件

路径：

```text
事件工坊 → 批量生成 → 选择事件类型
```

支持：

- MoveDecorations
- SetFilter
- MoveCamera
- SetFilterAdvanced
- MoveTrack
- RecolorTrack
- SetObject
- SetText
- EmitParticle
- SetParticle

### 6.1 基本输入

- 生成楼层：所有生成事件的所在楼层。
- 生成次数：生成多少个事件。
- 事件参数：按所选事件类型自动显示。

每个参数都可以使用数值表达式。X/Y 类参数会拆成两个独立输入框。

### 6.2 示例：批量生成移动装饰事件

目标：

- 在第 14 层生成 10 个 MoveDecorations。
- 标签依次为 s1 到 s10。
- angleOffset 依次为 0、20、40，直到 180。

填写：

```text
生成楼层：14
生成次数：10
tag：s[1]
angleOffset：inc(0,20)
```

其他参数留空。

### 6.3 枚举和固定格式

- 布尔字段填写 `true` 或 `false`。
- 颜色字段填写 `RRGGBB`，例如 `ffffff`。
- 枚举字段必须填写游戏中的枚举名。
- ease 注释区只展示三个示例，但其他合法 ease 值仍可填写。

## 7. 批量装饰

路径：

```text
事件工坊 → 批量装饰 → 选择装饰类型
```

支持：

- AddDecoration
- AddText
- AddObject
- AddParticle

操作方式与批量生成相同：

- 指定生成楼层。
- 指定生成次数。
- 按游戏参数表填写装饰参数。
- 使用相同的数值、文本和文件表达式。

### 7.1 装饰图片

文件类型参数右侧有“打开”按钮，可调用游戏原生文件选择器。

装饰图片路径也支持文本编号表达式，例如：

```text
img[1]x.png
```

生成结果：

```text
img1x.png
img2x.png
img3x.png
...
```

## 8. 推广移动装饰动画

路径：

```text
事件工坊 → 推广
```

推广用于复制源楼层中的 MoveDecorations 动画，并批量应用到不同标签的装饰上。

### 8.1 输入项

- 源楼层：动画模板所在的楼层。
- 目标楼层：复制后的 MoveDecorations 所在楼层。
- 源标签：只复制该标签的模板；留空则复制源楼层所有 MoveDecorations。
- 次数：复制多少组。
- 新标签表达式：例如 `a[1]`。
- 角度偏移增量：例如 `inc(0,5)`。

### 8.2 规则

每个复制事件只改变：

- floor：改为目标楼层。
- tag：按新标签表达式生成。
- angleOffset：原角度偏移 + 表达式增量。

其他参数保持不变。

### 8.3 示例

源楼层第 4 层有 5 个 MoveDecorations，标签全部为 `a`。

填写：

```text
源楼层：4
目标楼层：5
源标签：a
次数：100
新标签表达式：a[1]
角度偏移增量：inc(0,5)
```

结果：

- 第 1 组标签 a1，角度偏移增加 0。
- 第 2 组标签 a2，角度偏移增加 5。
- 第 3 组标签 a3，角度偏移增加 10。
- 直到第 100 组 a100。

推广只复制移动事件，不会自动创建对应标签的装饰对象。应先通过批量装饰生成这些装饰。

## 9. 批量调整

路径：

```text
事件工坊 → 批量调整
```

包含：

- 事件移动
- 参数批量调整

### 9.1 事件移动

先选择事件类型，再填写：

- 起始楼层
- 结束楼层
- 楼层运算表达式

示例：

```text
+10
v + 10
v + sin(i / 10 * pi) * 5
```

其中：

- `v` 是当前事件楼层。
- `i` 是匹配结果中的第几个事件。

### 9.2 参数批量调整

先选择事件类型，再选择要调整的参数。

X/Y 参数会拆成两个可选调整项。

示例：

```text
+10
*2
v * 2
v + sin(i / 10 * pi) * 20
clamp(v + i, 0, 100)
```

旧短格式仍然有效：

```text
+10
-5
*2
/2
```

## 10. 批量删除

路径：

```text
事件工坊 → 批量删除 → 选择事件类型
```

填写：

- 起始楼层
- 结束楼层

点击删除后，只会删除指定楼层范围内、指定事件类型的事件。

## 11. 表达式系统

所有数值参数共用同一套表达式语法。

### 11.1 变量

| 变量 | 含义 |
|---|---|
| `i` | 当前生成项或匹配项的序号，从 0 开始 |
| `n` | 本次生成总次数或匹配总数 |
| `v` | 批量调整时的当前参数值 |

生成、装饰和推广通常使用 `i`、`n`。

批量调整使用 `v`、`i`、`n`。

### 11.2 常数

| 写法 | 含义 |
|---|---|
| `pi` | 圆周率 3.14159265... |
| `e` | 自然常数 2.71828182... |

### 11.3 运算符

```text
+  -  *  /  ^  %  (  )
```

- `^`：乘方。
- `%`：取模。
- 支持一元负号。
- 空格会被忽略。
- 运算优先级遵循数学规则。

### 11.4 函数

| 函数 | 格式 | 示例 |
|---|---|---|
| 正弦 | `sin(x)` | `sin(i / n * 2 * pi)` |
| 余弦 | `cos(x)` | `cos(i * 0.1)` |
| 正切 | `tan(x)` | `tan(i)` |
| 反正弦 | `asin(x)` | `asin(v)` |
| 反余弦 | `acos(x)` | `acos(v)` |
| 反正切 | `atan(x)` | `atan(i)` |
| 双参数反正切 | `atan2(y,x)` | `atan2(i, 3)` |
| 绝对值 | `abs(x)` | `abs(-i)` |
| 平方根 | `sqrt(x)` | `sqrt(i)` |
| e 的幂 | `exp(x)` | `exp(i / 10)` |
| 自然对数 | `ln(x)` | `ln(i + 1)` |
| 常用对数 | `log(x)` | `log(i + 1)` |
| 以 2 为底对数 | `log2(x)` | `log2(i + 1)` |
| 向下取整 | `floor(x)` | `floor(i / 2)` |
| 向上取整 | `ceil(x)` | `ceil(i / 2)` |
| 取整 | `round(x)` | `round(v)` |
| 最小值 | `min(a,b)` | `min(i, 20)` |
| 最大值 | `max(a,b)` | `max(i, 0)` |
| 限制范围 | `clamp(x,lo,hi)` | `clamp(i, 0, 100)` |
| 取模 | `mod(a,b)` | `mod(i, 8)` |
| 乘方 | `pow(a,b)` | `pow(1.1, i)` |
| 随机 | `random(a,b)` | `random(0, 100)` |
| 递增 | `inc(a,b)` | `inc(0, 5)` |

### 11.5 inc 和 random

`inc(a,b)`：

```text
a + i * b
```

例如：

```text
inc(0,5)
```

生成：

```text
0, 5, 10, 15, 20...
```

`random(a,b)` 在两端之间随机取值。

### 11.6 整数截断

整数字段不做四舍五入。小数部分直接丢弃。

例如：

```text
0.9 → 0
1.9 → 1
-1.9 → -1
```

## 12. 文本编号表达式

文本字段会替换文本中的第一个 `[表达式]`。

### 12.1 单个整数

括号内是单个整数时，使用旧规则：

```text
a[1] → a1、a2、a3...
s[2] → s2、s3、s4...
```

### 12.2 编号位于中间

```text
s[1]s       → s1s、s2s、s3s
img[1]x.png → img1x.png、img2x.png
[1].png     → 1.png、2.png
```

### 12.3 编号表达式

方括号内可以使用变量、四则运算和函数：

```text
a[i * 2]b
a[inc(0, 2)]b
frame[1 + i].png
img[floor(i / 2)].png
```

标签和文件路径都支持此规则。

## 13. 正弦表达式注意事项

`sin` 使用弧度制，结果范围为 `-1` 到 `1`。

错误示例：

```text
sin(i / n * 40 * pi) * 2
```

当 `n = 20` 时：

```text
i / 20 * 40 * pi = i * 2 * pi
```

每个采样点都落在正弦零点，所以结果全部为 0。

完整一个周期可使用：

```text
sin(i / (n - 1) * 2 * pi) * 2
```

正向波动示例：

```text
sin(i / (n - 1) * 2 * pi) * 10 + 10
```

## 14. 撤销、保存和回滚

- 批量操作前会保存游戏编辑器的状态。
- 可尝试使用游戏原生撤销功能。
- 操作失败时会恢复批量操作前的 events 和 decorations。
- 操作完成后仍应通过游戏编辑器正常保存关卡。

建议在大规模操作前另存一份关卡备份。

## 15. 常见问题

### 15.1 参数没有效果

检查：

- 字段是否为整数字段，结果是否被截断为 0。
- 正弦结果是否过小。
- 是否发生采样混叠，例如所有采样点都在正弦零点。
- 目标装饰或对象是否存在。

### 15.2 事件显示为错误事件

检查：

- 必填字段是否有效。
- MoveTrack 的 startTile、endTile 是否有效。
- 枚举值是否使用正确名称。

### 15.3 文件选择失败

检查：

- 关卡是否已保存。
- 文件大小和格式是否受游戏支持。
- 文件是否被游戏复制到关卡目录。

### 15.4 表达式无效

根据界面错误检查：

- 括号是否成对。
- 函数参数数量是否正确。
- 枚举文本是否拼写正确。
- 变量是否为 `i`、`n` 或 `v`。
